## 1. Problem

Civic complaints arrive as scattered calls, tweets and WhatsApp photos. Cities can't tell severe from minor, the same pothole is reported dozens of times, and citizens never see a fix, so they stop reporting.

## 2. Solution

Photo -> YOLO11 finds damage -> severity score -> duplicates merged -> ranked "fix first" map -> before/after proof when fixed.

## 3. Why Cloudinary

- Face blur on every public image (privacy)
- g_auto smart thumbnails
- f_auto,q_auto for slow mobile networks
- Text-overlay share cards generated by URL
- Before/after composite with image layers
- Tags + context metadata as a searchable issue archive

## 7. Decisions we made (and why)

| Decision | Why |
|---|---|
| ONNX + onnxruntime instead of PyTorch at runtime | Fits a free 512 MB server; faster cold start |
| Merge reports within 25 m | Stops duplicates; turns repeats into a priority signal |
| Blur faces on every delivery URL | Citizens photograph streets with people in them |
| Web app, not native app | No install; works on any phone from a WhatsApp link |
